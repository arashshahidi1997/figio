## Phase 2a: Complete validation checks

The validate.py currently has 4 checks but 3 are missing or stubbed. Implement:

1. **min_font_pt check**: After rendering, parse the composed SVG for `font-size` attributes and `<style>` rules. Extract all font sizes (pt values). Compare against `target.min_font_pt`. Fail if any text element uses a font smaller than the minimum. This is critical for journal submission — Nature requires minimum 5pt.

2. **DPI check**: Currently stubbed as "checked at export time". For PNG export, verify that the actual pixel dimensions match `target.dpi * width_mm / 25.4`. Add this check in `build.py` after export, not just in validate.

3. **colorblind_check**: When `target.colorblind_check` is True, extract all fill/stroke colors from the composed SVG. Run a basic deuteranopia simulation (convert to LMS colorspace, zero the M channel, convert back) and check if any two distinct colors become indistinguishable (deltaE < 5). This can use a lightweight approach — no need for a full simulation library, just the color distance check on the palette. If implementing the full simulation is too complex, at minimum check the extracted palette against known problematic pairs (red/green) and warn.

Add tests in `tests/test_validate.py` (new file) covering:
- Font size pass/fail with synthetic SVG containing various font-size attributes
- DPI dimension check with known width/dpi combinations
- Colorblind palette check with red/green vs blue/orange palettes

Update CLAUDE.md validation section to reflect the new checks.
