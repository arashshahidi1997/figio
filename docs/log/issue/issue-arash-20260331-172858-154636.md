## Guide: Troubleshooting and FAQ

Create `docs/guide/troubleshooting.md` covering common issues:

1. "Panel shows only top-left corner" — viewBox/coordinate mismatch (the bug we just fixed); explain how figio handles coordinate mapping between matplotlib points and mm
2. "Panels overlap" — gap settings, layout dimensions
3. "Validation fails on figure_width" — target profile mismatch, panel sizing
4. "CairoSVG not found" — optional dependency, install with `figio[export]`
5. "make_figure not found" — function vs script execution modes
6. "Cache not invalidating" — when to use `--force`, what triggers cache miss (source change, style change, input change)
7. "SVG IDs conflict" — how ID prefixing works and edge cases
8. "Fonts don't match" — how style tokens map to matplotlib rcParams
