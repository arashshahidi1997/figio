## Phase 2e: Integration tests with real-world figure patterns

Add `tests/test_integration.py` with end-to-end tests covering realistic scientific figure patterns. Each test should write panel scripts to a tmp directory, create a spec, build, validate, and check the output.

Test cases:

1. **Single-panel nature figure**: One matplotlib panel, nature_single_column target, panel label, validate passes all checks. Verify SVG dimensions match 89mm width.

2. **Two-panel comparison**: Side-by-side panels (1x2 grid), equal_height constraint, panel labels A/B, caption annotation. Verify both panels appear in composed SVG, constraint equalizes heights.

3. **Four-panel grid (2x2)**: Four panels with different aspect ratios, equal_height per row, all panel labels, nature_double_column target. Verify layout positions are correct (4 distinct panel groups in SVG).

4. **Cache roundtrip**: Build, modify one panel source, rebuild. Verify only the changed panel re-renders (check cached_panels list). Then --force build and verify no panels are cached.

5. **Export formats**: Build with format=svg,pdf,png. Verify all three output files exist and have non-zero size. Verify PNG dimensions are roughly correct for the target DPI.

6. **Validation failure**: Create a spec where panel content would overflow figure width. Verify validation reports the overflow.

7. **Data dependencies**: Panel with `inputs: [data.csv]`. Change the data file, rebuild. Verify cache invalidated.

These tests should use pytest tmp_path fixture. Panel scripts should be minimal (simple shapes/lines) to keep tests fast. Mark any test requiring cairosvg with `pytest.mark.skipif` if cairosvg is not installed.
