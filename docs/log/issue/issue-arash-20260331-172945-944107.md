## Phase 2d: Script adapter — generic SVG-producing scripts

Implement the `script` generator backend at `src/figio/adapters/script.py`. This adapter handles any script that produces an SVG file:

1. Create `ScriptAdapter` class implementing `PanelAdapter` protocol
2. Execution model: run `panel.source` as a subprocess with `--output <tmp_path>.svg` argument. The script writes SVG to that path.
3. Read the output SVG, extract viewBox/dimensions, compute bbox_mm
4. Apply the same SVG normalization as matplotlib adapter (_prefix_ids, _extract_viewbox) — factor these out into svg_utils or a shared normalize module if needed
5. `supported_constraints()` returns `["equal_height", "equal_width"]` (no adapter-specific constraints)
6. Register in `build.py:_get_adapter()` for `Generator.script`

Convention for script panels:
- Script receives `--output PATH` as command-line argument
- Script receives `--width-mm FLOAT` and `--height-mm FLOAT` as hints
- Script must produce valid SVG at the output path
- Scripts can be any language (Python, R, Julia, bash wrapping inkscape, etc.)

Add tests in `tests/test_adapter_script.py`:
- Create a fixture script that generates a simple SVG rect
- Test render produces valid SVG with correct bbox
- Test ID prefixing works on script output
- Test integration with build pipeline (spec with generator: script)

Update docs/guide/adapters.md with the script adapter section.
