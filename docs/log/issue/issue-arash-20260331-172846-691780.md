## Tutorial: Multi-panel figure with constraints and annotations

The current quickstart only covers a single-panel figure. Create a comprehensive tutorial at `docs/guide/tutorial-multipanel.md` that walks through building a realistic 2x2 scientific figure:

1. Four panel scripts (line plot, bar chart, heatmap, scatter) using matplotlib
2. Grid layout with `rows: 2, cols: 2`
3. Constraints: `equal_height` across rows
4. All annotation types: panel labels (A, B, C, D), a caption below
5. Style tokens: font_family, font_size_pt, panel_gap_mm
6. Target profile: nature_double_column
7. Build with `--format svg,pdf,png`
8. Validate and interpret output

Place the panel scripts in `docs/guide/examples/multipanel/` so they're runnable. The tutorial should be self-contained — a reader following it should produce a working 4-panel figure.

Also add the tutorial to the nav in `mkdocs.yml` and link it from `docs/index.md`.
