## Phase 2c: Expand built-in target profiles

`targets.py` only has 3 profiles (nature_single_column, nature_double_column, default). Add profiles for major journals based on their actual submission guidelines:

Add to BUILTIN_TARGETS in targets.py:
- `science_single` — 55mm width, 6pt min font, 300 DPI
- `science_double` — 117mm width, 6pt min font, 300 DPI  
- `pnas_single` — 87mm width, 6pt min font, 300 DPI
- `pnas_double` — 178mm width, 6pt min font, 300 DPI
- `elife` — 140mm width, 7pt min font, 300 DPI, max_height_mm=225
- `plos_one` — 173mm width, 8pt min font, 300 DPI
- `cell_single` — 85mm width, 5pt min font, 300 DPI
- `cell_double` — 174mm width, 5pt min font, 300 DPI
- `ieee_single` — 88mm width, 8pt min font, 300 DPI
- `ieee_double` — 181mm width, 8pt min font, 300 DPI

Set `colorblind_check: True` for journals that require it in their guidelines (Nature, eLife, PLOS).

Add tests in test_schema.py:
- All new profiles resolve by name
- All have reasonable dimensions (width > 50mm, dpi >= 150)
- test_builtin_targets_complete still passes

Update the targets table in docs/guide/spec-format.md and docs/guide/targets.md (if it exists by then).
