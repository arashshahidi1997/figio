## Phase 2b: Composition polish — arrow markers, bracket annotations, shared_colorbar

Three incomplete features in composer.py need finishing:

1. **Arrow markers**: The arrow annotation generates a `<line>` with `marker-end="url(#arrowhead)"` but never injects the `<marker>` definition into `<defs>`. Add a `_build_marker_defs()` function that returns an SVG `<marker id="arrowhead">` element (simple triangle path). Call it in `compose()` and append to the defs content before `make_svg_document()`. The marker should be in mm units matching the composed viewBox.

2. **Bracket annotation**: Currently renders as a plain horizontal line. Replace with a proper curly bracket or square bracket SVG path. A square bracket is simpler: vertical lines at start and end with a horizontal connector. Position it above the bracketed panel group with the annotation text centered above.

3. **shared_colorbar constraint**: Add handler in `_apply_constraints()`. When panels share a colorbar, allocate extra width on the right side of the rightmost panel for a colorbar strip. Store the colorbar region in the BBox metadata. The actual colorbar rendering is adapter-specific — for now, just adjust the layout to reserve space (e.g., reduce each panel width by a fraction and add a colorbar column). Document that the adapter must provide colorbar SVG content.

Add tests for each:
- Arrow annotation produces SVG with both line and marker def
- Bracket annotation produces a bracket-shaped path, not just a line
- shared_colorbar constraint adjusts panel widths and reserves space

Update the existing test_composer.py.
